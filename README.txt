MY NOTEPAD — PERSONAL IPAD APP

This is a small offline-capable web app. It stores notes and drawings locally in the browser's IndexedDB database. There is no account, analytics, or cloud sync.

IMPORTANT:
- For reliable offline use and Add to Home Screen, host these files on an HTTPS static host (for example GitHub Pages).
- Open the hosted URL in Safari, tap Share > Add to Home Screen, enable Open as Web App if shown, then tap Add.
- Open the Home Screen app once while online, then test Airplane Mode.
- Export backup regularly. Clearing Safari/website data or deleting the web app may affect locally stored notes. Keep the backup file somewhere safe.
- Notes are local to this browser/app installation and do not automatically sync to other devices.
- This is a starter app; test it with non-important notes before relying on it.
